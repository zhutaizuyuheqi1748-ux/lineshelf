# 晾架（LineShelf）

基于 [Tendedero](https://github.com/alejandrobujan/tendedero) 的独立实验分支，保留截图和录屏入口，增加两个文件入口：

1. 从其他应用拖入本地文件，保存副本并挂到晾架上。
2. 自动显示“下载”目录中新到达的文件，方便使用网上下载、AirDrop 等保存到此处的内容。

Telegram、WhatsApp 等聊天应用是预期使用场景示例，尚未逐一验证兼容性；本功能不读取聊天记录或接入它们的账号。AirDrop 文件需要实际落到“下载”目录，晾架不接管传输协议。

下载文件仍留在原处；“取下”只隐藏卡片，“移到废纸篓”才删除原文件。手动拖入保存副本，来源文件保留。

构建和本地检查：

```sh
scripts/build-lineshelf.sh
scripts/test-lineshelf.sh
```

生成 `build/晾架.app`，为当前机器架构的本地签名版本。避免同时运行原版和晾架的截图接管模式。

此分支基于已验证的旧版上游源码，尚未与最新上游整合。发布内容仅包含源码、说明和运行时生成的合成测试，不包含个人文件、偏好设置、日志或本机录屏。

完整功能范围、存储位置、验证状态和限制见 [English README](README.md)。代码采用 MIT 许可，保留原作者版权说明；修改版使用独立名称和图标。
